The model must be supported by your provider account and Kong route. Prefer fixing Haiku and token limits on the gateway; client-side limits are not security controls.



Required Kong and GitHub Pages setup

Configure an Anthropic AI Proxy chat route on your gateway. Store the Anthropic key server-side. The default request format uses OpenAI-style chat completions; use native format only if your route supports it.


For a page at https://USERNAME.github.io/REPOSITORY/, its origin is https://USERNAME.github.io. Configure Kong CORS to allow that origin, POST and OPTIONS, and Content-Type plus Authorization or apikey as needed. Preflight requests must be handled successfully.


For cookie sessions, allow credentialed CORS with the exact origin, not a wildcard. Cross-site cookie restrictions may still affect sessions.


Protect the gateway with authentication, rate limits, quotas, and fixed model/token policies. Browser credentials are visible to their user; use short-lived limited tokens or an authenticated backend session. Never commit provider keys or permanent shared credentials to GitHub.
